# משחקי אמה ואבא

אפליקציית אנדרואיד בלי פרסומות ובלי אינטרנט, עם 8 משחקים לשניים. בכולם הכלים הם הפרצופים של השחקנים:

- **דמקה** – המלך מקבל את הפרצוף של השחקן.
- **שש-בש** – כל הכלים עם הפרצופים, כולל מארס טורקי עם צחוק.
- **איקס מיקס דריקס**, **ארבע בשורה**, **חמש בשורה**, **רברסי**
- **משחק זיכרון** – זוגות של תמונות השחקנים ואימוג'ים.
- **סולמות וחבלים** – כשנופלים בחבל, השחקן השני צוחק.

אפשר להוסיף שחקנים עם תמונה מהמצלמה או מהגלריה, ולהקליט לכל שחקן צחוק שמתנגן כשהוא מנצח.
משחקים שניים על אותו טלפון או נגד המחשב (קל / בינוני / קשה).

## התקנה
כל דחיפה לגיטהאב בונה APK אוטומטית (GitHub Actions) ומפרסמת אותו ב-**Releases**.
בטלפון: נכנסים ל-Releases, מורידים את `EmmaGames.apk`, פותחים ומאשרים "התקנה ממקור לא ידוע".

## מבנה
- `app/src/main/assets/` – המשחקים עצמם (HTML/JS), והתמונות `emma.jpg`, `dad.jpg`.
- `app/src/main/java/.../MainActivity.java` – מעטפת WebView מסך מלא.
- בדיקה מהירה במחשב: לפתוח את `app/src/main/assets/index.html` בדפדפן.
