# דמקה ושש-בש – המשחקים של אמה ואבא

אפליקציית אנדרואיד בלי פרסומות ובלי אינטרנט, עם שני משחקים:

- **דמקה** – חיילים שחורים ולבנים. חייל שמגיע לקצה הופך למלך: המלך השחור הוא אמה, המלך הלבן הוא אבא.
- **שש-בש** – כל הכלים עם הפרצופים: שחור = אמה, לבן = אבא.

אפשר לשחק שניים על אותו טלפון או נגד המחשב (קל / בינוני / קשה).

## התקנה
כל דחיפה לגיטהאב בונה APK אוטומטית (GitHub Actions) ומפרסמת אותו ב-**Releases**.
בטלפון: נכנסים ל-Releases, מורידים את `EmmaGames.apk`, פותחים ומאשרים "התקנה ממקור לא ידוע".

## מבנה
- `app/src/main/assets/` – המשחקים עצמם (HTML/JS), והתמונות `emma.jpg`, `dad.jpg`.
- `app/src/main/java/.../MainActivity.java` – מעטפת WebView מסך מלא.
- בדיקה מהירה במחשב: לפתוח את `app/src/main/assets/index.html` בדפדפן.
